# Ground Variants

This document specifies the pixel-art production model and gradient tile replacement rules for the ground variants introduced in WG.21.01.

## PixelLab MAPS Schema
When generating these tiles using PixelLab MAPS, use the following schema:
- \`tile_type\`: \`square_topdown\`
- \`tile_size\`: \`48\`
- Strict high top-down perspective with no isometric extrusion
- No outline
- No \`tile_feature\`

## Design & Grading
- V1: Dampest, most vibrant, visually closest to the base A2 shape
- V2: A2 block 
- Vn: Driest, sparsest
