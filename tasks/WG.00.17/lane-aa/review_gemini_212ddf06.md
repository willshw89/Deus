   - Fast inline identity check for `isLevel(z)`.
   - Dynamic `World.LEVELS` initialized as frozen array matching active range.
   - Deterministic map ID slots preserving legacy slots (0, 1, 2, 3, 4) and mapping +z to `2z - 1`, -z to `2z`.
   - Static scan tool `tools/zrange/scan_z_literals.js`: 133 lines with Z-pattern across 22 plugins, 133 permitted by 110 allowlist entries, 0 unallowed, 0 stale.

2. **Sparse Storage (`DEUS_Levels.js`, `DEUS_Fluid.js`, `DEUS_World.js`):**
   - 32x32 chunk format (`CH = 32`) matching ADR-003 Section 15.3.
   - Directory array `Uint16Array(nc)` referencing palette for UNIFORM chunks; `0xffff` for MIXED.
   - Uniform chunks consume only 2 bytes per 32x32 chunk in the directory; outer layers (-16..-3, +3..+15) outside the mountain rock are 100% UNIFORM.
   - First edit to a uniform chunk calls `splitChunk(b, c)` without allocating whole-level dense arrays.
   - Saves serialize modified cells only; fresh save difference between -16..+15 and -4..+4 is 2 bytes (well within the 256 B bound).

3. **Natural Terrain Heights & Biome Bands:**
   - Natural core generation produces terrain on levels -2..+2. Mountain caps from +2 ceiling caps materialize upward via `materializeCaps` filling strata into +3..+5 (maximum observed thickness ~12 strata = up to level +5).
   - Above level +5 up to level +15 is 100% open air (`outerBaseline(z)`).
   - Natural terrain strictly tops out below +11 (confirmed at <= +5). The upper layers (+12..+15) are reserved open air for construction.
   - Biome bands: Deep Earth (-16..-11), Caverns (-10..-5), Lowlands (-4..+1), Uplands (+2..+6), Highlands (+7..+11) are noted as future content work (WG.62.02) and tracked as follow-up `PROPOSED-AA-03`.
