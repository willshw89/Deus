## Owner facts (non-negotiable)
1. **32 layers** (DEC-013 as amended, `docs/OWNER_DECISIONS.md` ~L172-195). The **default split is -16..+15** (surface 0; 16 below, 15 above; 320 ft). DEC-013 records the coordinate mapping as a PM default that the Owner may still change, so the range is **data** (one setting), never a literal anywhere.
2. **Scale** (DEC-013 item 2; Owner ruling D-2 relayed in 0035-AJ): 1 square = **5 ft x 5 ft**; 1 layer = **10 ft**; 5 strata per layer = **2 ft per stratum**. The code's 1-ft strata / 5-ft (or 6-ft) level assumptions are stale and are fixed in this lane: `Z_STEP_FEET` (`DEUS_World.js` ~L255), the stratum comments and sphere math of `applyVolumeDamage` (`DEUS_Levels.js` ~L985-986, ~L1783-1876), the "6 ft level" in `DEUS_Depth.js` (~L164-205). Each feet change gets a before/after fixture (ADR-003 R13).
3. **Sparse storage is mandatory for memory and for saves** (DEC-013 item 3; Owner ruling D-3 in 0035-AJ). Memory and save size scale with occupied/changed cells, not with 32 x area. Empty sky and untouched solid rock cost near zero. Uniform columns/chunks are stored compactly, levels are allocated on demand, 3D path-search scratch is bounded to the layers a route can reach.
4. **9-layer test mode must keep working** (DEC-013 item 1; WBS row): range -4..+4 runs in automated tests.
5. **DEC-011: every layer renders 1:1.** No blur, scale, zoom, parallax, projection offset, ColorMatrix, alpha/tint depth shading or any other filter. Depth cues 7-9 are NOT in scope. DEUS_Depth keeps drawing at most `MaxDepth` (2) levels below the viewed level; the planes' draw cost must not grow with the layer count (DEC-021's occlusion rule itself is WG.00.21, not this lane).
6. **Existing 5-level saves** (ADR-003 Q16 is still open for the Owner; its proposed answer is "keep old saves at 5; new worlds at 32"): an old save loads at its recorded range -2..+2 and plays as before. New worlds use the default range. Do NOT build an upgrade path that generates new layers into an old world; keep the range per world in the save so the Owner can choose later.
7. Ore never respawns; matter is never created (LIFE-001/002, D-5). This lane moves storage; it must not change any world's matter. The ledger (`game/js/sim/ledger*.js`, read only) is the check.
